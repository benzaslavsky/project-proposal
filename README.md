# Contextify

## What and why:
I'm sure that everyone uses AI. I'm also sure that everyone has heard of this thing called a rate limit. Some of us have multiple AI subscriptions. It's pretty annoying to keep switching back and forth between AIs, because one doesn't have the context you gave it and the context that it generated on its own, so it feels like you start from square 1 every time. The idea is an automatic context compacter/switcher between your subscriptions.

## For whom:
Mainly developers and SWEs, since they hit rate limits often. But really, its for any advanced users of AIs.

## How:
I can't imagine this to be very user-facing. This is mainly a backend issue, and if running on the computer, should really run autonomously, especially for Codex/CC which doesn't run on the web. If on the phone, maybe just a button for it to fetch the chats and feed it into the memory of the others.

## Scope:
Yes, this is doable.
